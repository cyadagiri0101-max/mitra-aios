## 1. Idempotency Key

The unique event identity tuple is:

$$\mathcal{K}_{\text{signal}} = \langle \text{tenantId}, \text{sourceId}, \text{signalType}, \text{eventTimestamp} \rangle$$

Repeated signals matching $\mathcal{K}_{\text{signal}}$ return the existing persisted entity with zero mutation.
