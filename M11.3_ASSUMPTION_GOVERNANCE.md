# M11.3 Assumption Governance Specification

## 1. Assumption Lifecycle & Classification
Every engineering reasoning result must explicitly enumerate all working assumptions with their verification status:

- `VERIFIED`: Explicitly configured and confirmed by the engineering team or project master data (0% confidence penalty).
- `UNVERIFIED_ASSUMPTION`: Default baseline assumption used in the absence of project-specific configuration (penalizes confidence by 8% to 15%).

```typescript
export interface Assumption {
  assumptionId: string;
  description: string;
  source: string;
  status: AssumptionStatus;
  verifiedAt: string | null;
  verifiedBy: string | null;
  impactOnConfidence: number;
}
```
