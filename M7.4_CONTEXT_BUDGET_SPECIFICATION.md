# M7.4 — Context Budgeting & Token Management Specification
## Deterministic Context Assembly & Budget Constraints
**Milestone:** `M7.4`  
**Status:** Certified Specification  
**Module:** `src/modules/engineering-library/grounding`

---

## 1. Budget Parameters

| Parameter | Default Value | Maximum Bound | Purpose |
| :--- | :---: | :---: | :--- |
| **`maxChunks`** | 8 | 12 | Number of top-ranked chunks included in prompt context. |
| **`maxTotalChars`** | 8,000 | 12,000 | Character cap (~2,500 tokens) fitting Phi-3 context window. |
| **`maxPerEntity`** | 2 | 3 | Limits chunk dominance from a single table or document. |
| **`minChunkScore`** | 0.15 | 0.80 | Minimum retrieval score threshold required for inclusion. |

---

## 2. Invariants
- **No Mid-Row Truncation:** Markdown table headers and data rows are preserved intact.
- **Deterministic Citation Assignment:** Chunks are assigned sequential citation IDs (`[REF-1]`, `[REF-2]`, ..., `[REF-N]`) in descending order of retrieval rank.
