## Invalid Dependencies

| # | Invalid Dependency | Problem |
|---|-------------------|---------|
| ID-1 | Runtime overwrites tooling index | `RepositoryScannerPlugin` writes to same path as `scan-repository.py` but with less data |
| ID-2 | Two state systems write different files | `StatePlugin` writes `runtime-state.json`; `generate-state.py` writes 5 other files. No coordination |
| ID-3 | Two context caches | `ContextPlugin` writes `context-cache.json`; `load-context.py` writes `context.json`; `smart-loader.py` writes `context-{mode}.json`. Three different files, three different formats |
| ID-4 | Tooling scripts have no dependency on runtime | `orchestrate.py` calls scripts via subprocess, completely bypassing the runtime |
| ID-5 | Reports directory has no generator | 39 SVF reports are manually created. Neither runtime nor tooling generates them |
| ID-6 | Knowledge layer disconnected | 6 JSON stubs exist but no component reads or writes them |
| ID-7 | Engagement state manually maintained | `engagement.yaml` and `current-engagement.yaml` have no automated generator |
| ID-8 | Architecture documents disconnected | 20 scaffolding docs exist but no component references them |

## Target State — Dependency Graph

```
aios/
├── core/
│   ├── runtime.py          ← Single orchestrator
│   ├── config.py           ← Single configuration
│   └── logging.py          ← Single logging
│
├── engines/
│   ├── state_engine.py     ← One state API (generate/sync/validate/diff/history)
│   ├── event_engine.py     ← Event bus (emit/subscribe)
│   └── recovery_engine.py  ← Session recovery (checkpoint/resume)
│
├── plugins/
│   ├── scanner/            ← RepositoryScannerPlugin (MERGED from tooling)
│   ├── indexer/            ← DocumentRegistry + FrameworkRegistry + Consolidator (NEW from tooling)
│   ├── context/            ← ContextPlugin (MERGED from smart-loader.py)
│   ├── validator/          ← ValidationPlugin (MERGED from validate-repository.py)
│   ├── reporting/          ← ReportingPlugin (MERGED from generate-health-report.py)
│   └── health/             ← Health scoring (NEW from generate-health-report.py)
│
├── cli/
│   └── cli.py              ← argparse-based CLI
│
├── state/                  ← Generated artifacts only
├── events/                 ← Event log
├── context/                ← Context cache
├── utils/                  ← Shared utilities (hashing, file walking, YAML)
└── providers/              ← Future: model provider abstraction
```

**Key changes:**
- `tooling/scripts/` eliminated — all logic merged into `aios/plugins/`
- One state engine replaces `StatePlugin` + `generate-state.py`
- One context loader replaces `ContextPlugin` + `load-context.py` + `smart-loader.py`
- One validator replaces `ValidationPlugin` + `validate-repository.py`
- Event engine enables automatic state/index/cache updates
- Recovery engine enables `aios resume` with zero conversation history
