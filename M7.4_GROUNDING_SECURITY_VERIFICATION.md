## 1. Multi-Tenant Scoping Guarantees

1. **Retrieval Tenant Filtering:** Every candidate query enforces `WHERE c.tenant_id = :tenantId`.
2. **Context Tenant Confinement:** Context builder strictly receives only results belonging to the authenticated session's `tenantId`.
3. **Citation Registry Confinement:** Citation tags in the response map exclusively to chunks indexed under the caller's tenant.
4. **Cross-Tenant Adversarial Tests:**
   - Querying Tenant A's project numbers while authenticated as Tenant B produces 0 results and returns the safe refusal message: `"The engineering library does not contain sufficient evidence to answer this reliably."`
   - Zero leakage observed.

## 2. Adversarial Hallucination & Prompt Injection Defense

1. **Hallucinated Tag Stripping:** If an adversarial prompt tricks the LLM into generating unlisted citations (e.g. `[REF-999]`), `EngineeringCitationValidatorService` strips or rejects the tag and flags `hallucinatedCitationsDetected > 0`.
2. **Strict Air-Gapping:** Zero external HTTP requests to OpenAI, Anthropic, or external cloud endpoints; 100% of inference is hosted on the local Ollama instance (`http://localhost:11434`).
