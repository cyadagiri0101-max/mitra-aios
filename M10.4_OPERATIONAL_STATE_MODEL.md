## 1. Operational Dimensions

- `activeWorkOrdersCount`: Active work orders in machining / assembly / inspection.
- `averageCycleTimeSec`: Real-time empirical mean cycle time calculated from high-frequency sensor signals.
- `cycleTimeDeviationPct`: Percentage deviation relative to standard engineering benchmark ($60\text{ s}$).
- `anomaliesDetected`: Flag set if deviation $> 15\%$.
