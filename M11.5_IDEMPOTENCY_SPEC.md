# M11.5 Idempotency Specification

## 1. SHA-256 Evidence Hashing
`EngineeringReasoningEngineService` computes a deterministic SHA-256 hash across:
- `findingId`
- `drawingRevision`
- `parameters`
- `material`
- `processType`

If an identical analysis request is submitted for the same evidence hash, the system returns the existing reasoning result without triggering redundant AI inference or generating duplicate database records.

## 2. Review Decision Idempotency
Submitting an identical review decision updates the existing record with the latest timestamp while preserving review history in the audit ledger.
