## 2. Hard Safety & Grounding Boundaries

1. **Grounding Only:** The local LLM (Phi-3) must answer **ONLY** from supplied retrieval context; it must never act as an ungrounded source of truth.
2. **Deterministic Citation Registry:** Citation tags (`[REF-1]`, `[REF-2]`) and their underlying provenance are constructed deterministically by the application, never fabricated by the LLM.
3. **Citation Validation:** Any hallucinated or mismatched citation tag generated by the model must be caught and rejected by `EngineeringCitationValidatorService`.
4. **Refusal on Insufficient Evidence:** If retrieved context is insufficient, the system must deterministically return:  
   `"The engineering library does not contain sufficient evidence to answer this reliably."`
5. **Zero Cloud Dependencies:** All inference and embeddings remain strictly local via Ollama (`phi3`, `nomic-embed-text`).
