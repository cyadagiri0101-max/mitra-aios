# M10.6 — Cross-Domain Query Specification
## Cited Grounding for Complex Engineering Questions
**Milestone:** `M10.6`  
**Status:** **AUTHORITATIVE**

---

## 1. Query Execution Flow

1. User submits natural language inquiry with optional `projectId`.
2. EKOS retrieves matching graph nodes (Drawings, NCRs, Work Orders).
3. G13 Cited RAG synthesizes an evidence-grounded response citing exact entity IDs and labels.
4. Response is logged in the audit ledger with query metadata.
