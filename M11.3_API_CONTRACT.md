# M11.3 API Contract Specification

## Endpoints

### 1. Multi-Step Reasoning Pipeline
- `POST /api/engineering/reasoning/evaluate`
  - Body: `EvaluateEngineeringReasoningDto` (`drawingId`, `projectId`, `drawingRevision`, `sourceFindingId`, `material`, `processType`, `manufacturingContext`)
  - Response: `EngineeringReasoningResult`
  - Roles: `ADMIN`, `ENGINEERING`, `QUALITY`, `PLANNING`

- `GET /api/engineering/reasoning/:id`
  - Response: `EngineeringReasoningResult`

- `GET /api/engineering/reasoning/:id/evidence`
  - Response: `{ reasoningId: string, evidence: EvidenceItem[] }`

- `GET /api/engineering/reasoning/:id/cost`
  - Response: `{ reasoningId: string, costSummary: CostSummary }`

- `GET /api/engineering/reasoning/:id/recommendation`
  - Response: `{ reasoningId: string, recommendation: Recommendation }`

- `POST /api/engineering/reasoning/:id/review`
  - Body: `ReviewReasoningResultDto` (`status`, `decisionNotes`, `modifiedRecommendation`)
  - Response: `EngineeringReasoningResult`
  - Roles: `ADMIN`, `ENGINEERING`, `QUALITY`

- `GET /api/engineering/dfm/findings/:id/reasoning`
  - Response: `EngineeringReasoningResult[]`

### 2. Cost Configuration Management
- `POST /api/engineering/cost-configurations`
- `GET /api/engineering/cost-configurations`
- `GET /api/engineering/cost-configurations/:id`
- `PUT /api/engineering/cost-configurations/:id`
- `DELETE /api/engineering/cost-configurations/:id`
