## 1. Response Structure

- `projectId`: Target project UUID
- `projectName`: Project label
- `commercialCommitment`: Associated RFQ count
- `engineeringArtifactsCount`: Drawing and BOM count
- `activeWorkOrdersCount`: Active work orders
- `qualityIssuesCount`: Active NCR / CAPA count
- `governedKnowledgeArticlesCount`: Associated knowledge articles
- `predictiveSignals`: Delay and capacity risk tiers
