## 2. Infrastructure Inventory & Reusability Assessment

### A. Knowledge Persistence (`src/modules/knowledge`)
- `KnowledgeCatalogEntry` (`knowledge_catalog`): Canonical catalog containing 3,474 entries from M7.1 with `sourceRef` (row data, pk, tableName, file coordinates, sha256).
- `KnowledgeArticle` (`knowledge_articles`): Technical documentation repository.
- `TenantAwareService`: Enforces `tenantId` boundaries on all repository queries.

### B. Engineering Library Ingestion (`src/modules/engineering-library`)
- `KnowledgeSource` (`knowledge_sources`): Tracks cataloged sources with `sha256`, `relativePath`, `authorityStatus`, `classification`, and domain metadata.
- `KnowledgeIngestionBatch` (`knowledge_ingestion_batches`): Tracks batch state (`QUEUED`, `RUNNING`, `COMPLETED`, `PARTIAL`, `FAILED`).
- `KnowledgeIngestionItem` (`knowledge_ingestion_items`): Tracks item-level steps.

### C. AI & Embedding Layer (`src/modules/ai`)
- `KnowledgeEmbedding` (`knowledge_embeddings` table): Existing pgvector-compatible entity storing `entityType`, `entityId`, `contentHash`, `contentText`, `embedding` (string vector), `modelName` (`nomic-embed-text`), `metadata`.
- `EmbeddingService`: Local embedding service with `upsertEmbedding`, `sha256`, `deterministicVector` offline fallback, and `generateEmbedding`.
- `OllamaProvider`: Local Ollama adapter supporting `nomic-embed-text` with configurable timeout and graceful offline degradation.
- `VectorSearchService`: Cosine similarity query execution over `knowledge_embeddings`.
