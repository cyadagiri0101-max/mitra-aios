### Backend Container Reachability

**Command:**
```bash
podman exec mitra30_backend_1 wget -qO- --post-data='{"model":"nomic-embed-text","prompt":"test"}' \
  --header='Content-Type: application/json' http://ollama:11434/api/embeddings
```

**Result:** ✅ Backend reaches container Ollama and receives embedding vector.

### Fix Applied

`nomic-embed-text` was not visible via `/api/tags` after CLI pull. The model cache in the running Ollama server was stale. Fix:

```bash
curl -X POST http://localhost:11434/api/pull -H "Content-Type: application/json" \
  -d '{"model":"nomic-embed-text"}'
```

Pulling through the Ollama API registered the model in the server's live model list. `/api/tags` now shows:

- `nomic-embed-text:latest` (family: nomic-bert, 137M, embedding capability)
- `phi3:latest`
- `openchat:latest`
