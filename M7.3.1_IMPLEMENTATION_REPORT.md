## 3. Key Changes Implemented

1. **Provenance & Project Extraction:** Hardened `EngineeringNormalizerService` to extract project numbers, customer names, machines, and revisions from `source_file` across all tables.
2. **Weighted Lexical Scoring:** Increased project number weight to $1.5$, machine/material to $1.0$, customer to $0.8$, and body text to $0.4$ in `EngineeringLexicalSearchService`.
3. **Query-Type-Aware Adaptive RRF:** Implemented dynamic fusion weights in `EngineeringRetrievalService` ($w_{\text{lex}} = 2.5, w_{\text{vec}} = 0.6$ for identifier queries) to eliminate semantic dilution of exact keyword hits.
4. **Calibrated Reranker Boosts:** Boosted exact project matches ($+0.35$), exact part descriptions ($+0.30$), machines/materials ($+0.25$), and phrases ($+0.20$) in `EngineeringRerankerService`.
