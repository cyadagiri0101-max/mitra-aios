## Chronological Splitting & Out-of-Time Evaluation
**Milestone:** `M9.2`  
**Status:** **AUTHORITATIVE**

---

## 1. Temporal Splitting Protocol

1. **Chronological Ordering:** Historical snapshots are sorted strictly ascending by `predictionCutoff`.
2. **Partitioning:**
   - **Training Set (Earliest 70%):** Models parameters $w_0, w_1, \dots, w_{20}$.
   - **Validation Set (Middle 15%):** Evaluates out-of-sample MAE/RMSE and computes residual standard deviation $\sigma$.
   - **Test Set (Most Recent 15%):** Out-of-time benchmark evaluation.
3. **Zero Random Shuffling:** Eliminates temporal lookahead bias and guarantees realistic evaluation on forward forecasts.
