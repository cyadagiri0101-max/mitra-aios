# M9.3 — Temporal Validation Specification
## Chronological Ordering & Forward Validation Splits
**Milestone:** `M9.3`  
**Status:** **AUTHORITATIVE**

---

## 1. Temporal Splitting Protocol

1. **Chronological Sorting:** Historical capacity snapshots are ordered ascending by `predictionCutoff`.
2. **Data Partitioning:**
   - **Training Set (Earliest 70%):** Learns Ridge regression weights $w_0, \dots, w_{15}$.
   - **Validation Set (Middle 15%):** Computes out-of-sample prediction residual dispersion $\sigma$.
   - **Test Set (Most Recent 15%):** Out-of-time benchmark evaluation.
3. **No Random Cross-Validation:** Prohibits time leakage and ensures realistic out-of-time evaluation on future shop-floor loads.
