# M11.3 Contradiction Governance Specification

## 1. Contradiction States
Engineering evidence can conflict across geometry, physical trials, and historical quality records. MITRA strictly prohibits silently resolving or ignoring conflicting data.

| State | Definition | System Action |
|---|---|---|
| `NO_CONFLICT` | Deterministic geometry rules, historical defect records, and material data agree. | Proceed with standard confidence scoring. |
| `CONFLICT_PRESENT` | Evidence sets contradict (e.g. historical data shows feature was safe, but rule engine flags failure). | Apply 25% confidence penalty; highlight conflict in UI. |
| `INSUFFICIENT_EVIDENCE` | Zero historical shop floor records exist for the feature pattern. | Mark state and recommend physical molding trial run. |
| `REQUIRES_ENGINEERING_REVIEW` | High-severity discrepancy requiring lead engineer arbitration. | Block automated signoff; require human resolution notes. |
