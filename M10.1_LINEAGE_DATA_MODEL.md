# M10.1 — Lineage Data Model Specification
## Schema, Attributes & Persistence Architecture
**Milestone:** `M10.1`  
**Status:** **AUTHORITATIVE**

---

## 1. Table Schema: `ekos_graph_nodes`

- `id`: UUID PRIMARY KEY
- `tenant_id`: UUID NOT NULL
- `entity_type`: VARCHAR(100) NOT NULL
- `entity_id`: UUID NOT NULL
- `entity_revision`: VARCHAR(50) NULL
- `project_id`: UUID NULL
- `label`: VARCHAR(255) NOT NULL
- `metadata`: JSONB NOT NULL DEFAULT '{}'
- `provenance_source`: VARCHAR(100) NOT NULL DEFAULT 'SYSTEM'
- `provenance_hash`: VARCHAR(64) NULL
- `valid_from`: TIMESTAMPTZ NOT NULL DEFAULT NOW()
- `valid_to`: TIMESTAMPTZ NULL
- `is_superseded`: BOOLEAN NOT NULL DEFAULT FALSE
- `created_at`, `updated_at`: TIMESTAMPTZ NOT NULL

---

## 2. Table Schema: `ekos_graph_edges`

- `id`: UUID PRIMARY KEY
- `tenant_id`: UUID NOT NULL
- `source_node_id`: UUID NOT NULL REFERENCES `ekos_graph_nodes(id)` ON DELETE CASCADE
- `target_node_id`: UUID NOT NULL REFERENCES `ekos_graph_nodes(id)` ON DELETE CASCADE
- `relation_type`: VARCHAR(100) NOT NULL
- `provenance_type`: VARCHAR(50) NOT NULL DEFAULT 'TRANSACTIONAL_EVENT'
- `project_id`: UUID NULL
- `confidence`: NUMERIC(5, 4) NOT NULL DEFAULT 1.0000
- `properties`: JSONB NOT NULL DEFAULT '{}'
- `is_superseded`: BOOLEAN NOT NULL DEFAULT FALSE
- `valid_from`: TIMESTAMPTZ NOT NULL DEFAULT NOW()
- `valid_to`: TIMESTAMPTZ NULL
- `created_at`, `updated_at`: TIMESTAMPTZ NOT NULL
