# M8.5 — Deterministic Citation Specification
## Structured Citation Generation, Formatting & Coordinate Authority
**Milestone:** `M8.5`  
**Status:** **SPECIFICATION COMPLETE**

---

## 1. Deterministic Citation Schema

Every attached G13 evidence link generates a deterministic citation label based on its ordered sequence:
$$\text{Label} = \text{"[REF-" + sequenceNumber + "]"}$$

### Provenance Coordinate Format:
- **Workbook Row Chunks:**  
  `[REF-1] MOL-001_Design_Standard.xlsx#ToolingParams:R14 (Authority: AUTHORITATIVE_RELEASE, Hash: sha256_...)`
- **Document Page Chunks:**  
  `[REF-2] ISO_20482_Milling_Spec.pdf#page:4 (Authority: AUTHORITATIVE_RELEASE, Hash: sha256_...)`

---

## 2. Deterministic Ordering Invariants

When citations are rendered or returned via API:
1. `sequenceNumber` (Ascending, starting from 1)
2. `sourceFile` (Lexicographical ascending)
3. `sourceCoordinate` (Ascending)
4. `chunkId` (UUID ascending)

---

## 3. Strict Citation Validation (No Spoofing)

Manual text citations (e.g. `[REF-1] made up claim`) submitted without backing `chunkId` validated against `knowledge_chunks` are rejected with `BadRequestException`. Only validated G13 chunks can generate citations.
