# M11.5 Threat Model Document

## 1. Threat Vectors Analyzed
- **T1: Unauthorized Cross-Tenant Geometry / DFM Inspection**: Mitigated by mandatory `tenantId` extraction from validated JWT token on every controller route.
- **T2: Reasoning Evaluation Resource Exhaustion / Denial of Service**: Mitigated by `ENGINEERING_REASONING_THROTTLE` (30 req/min) and SHA-256 evidence hashing idempotency cache.
- **T3: Stale Analysis Decision Injection**: Mitigated by revision validation checking `activeRevision === analysisRevision`.
- **T4: Unconfigured Cost Rate Fabrication**: Mitigated by returning `COST_NOT_CONFIGURED` (`UNAVAILABLE`) with `null` values.
- **T5: Autonomous CAD Mutation**: Mitigated by architectural boundary: advisory recommendations only; CAD files and BOMs remain 100% read-only.
