## 2. Capabilities
- Grounded Evidence Browser supporting:
  - `GEOMETRIC_FEATURE`
  - `DFM_FINDING`
  - `HISTORICAL_NCR`
  - `TRIAL_OBSERVATION`
  - `CAPA`
  - `MATERIAL_MASTER`
  - `PROCESS_PLAN`
- G13 Authoritative Citations with clickable resolver button.
- Traceability metadata: Source entity, ID, revision, timestamp, authority.
