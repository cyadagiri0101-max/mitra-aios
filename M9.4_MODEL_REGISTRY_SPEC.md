# M9.4 — Model Registry Specification
## Governed Canonical Model Registry Schema & Capabilities
**Milestone:** `M9.4`  
**Status:** **AUTHORITATIVE**

---

## 1. Registry Architecture & Entities

1. **Table:** `g14_model_registry`
2. **Key Attributes:**
   - `id`: Unique UUID.
   - `tenantId`: Strict tenant scoping.
   - `modelFamily`: e.g. `G14_PREDICTIVE`.
   - `capability`: Enum (`DELAY_PREDICTION`, `CAPACITY_FORECAST`, `BOTTLENECK_FORECAST`).
   - `modelVersion`: Immutable version identifier.
   - `featureVersion`: Compatible feature contract (e.g. `G14_FEATURES_V1`, `G14_CAPACITY_V1`).
   - `algorithm`: e.g. `RIDGE_REGRESSION`.
   - `weights`: JSONB array of feature weights.
   - `intercept`: Base model bias.
   - `residualStdDev`: Out-of-sample residual standard deviation for uncertainty intervals.
   - `evaluationMetrics`: Complete evaluation metrics dictionary.
   - `status`: Lifecycle state (`TRAINED`, `EVALUATED`, `PENDING_APPROVAL`, `APPROVED`, `ACTIVE`, `RETIRED`, `ROLLED_BACK`, `REJECTED`).
   - `artifactHash`: Deterministic SHA-256 digest of artifact payload.
   - `provenanceHash`: SHA-256 digest of training dataset IDs.
   - `approvedBy`, `approvalNotes`, `activatedAt`, `retiredAt`, `rolledBackAt`, `rollbackReason`.
