## 1. Query Classification Taxonomy

The 50 golden queries are categorized into five deterministic engineering classes:
1. **`EXACT_IDENTIFIER`** (4 queries): Queries containing explicit unique keys (e.g. `BM454`, `BM377`).
2. **`ENGINEERING_ATTRIBUTE`** (21 queries): Queries specifying technical materials, machines, grades, or dimensions.
3. **`DOMAIN_LOOKUP`** (13 queries): Standard domain entity requests (BOM lists, cycle time history, process sequences).
4. **`SEMANTIC_ENGINEERING`** (5 queries): Conceptual descriptions (e.g. data dictionary terminology, cavitation derivation reasons).
5. **`MULTI_CONSTRAINT`** (7 queries): Queries combining project number, material, machine, and component constraints simultaneously.
