# M11.4 Engineering Workspace Specification

## 1. Scope and Mission
Defines the technical specifications for the unified engineering review workspace container (`DfmReviewWorkspace.tsx`).

## 2. Aggregated Data Contract
The workspace coordinates data from the unified backend aggregation endpoint:
`GET /api/engineering/drawings/:drawingId/analysis-workspace?revision=RevB`

Response Payload:
- `drawingId`: string
- `activeRevision`: string
- `analysisRevision`: string
- `revisionSafetyStatus`: `'REVISION_MATCH_VERIFIED'` | `'REVISION_MISMATCH_DETECTED'`
- `featuresCount`: number
- `findingsCount`: number
- `correlationsCount`: number
- `reasoningResultsCount`: number
- `features`: `GeometricFeature[]`
- `findings`: `DfmFinding[]`
- `correlations`: `HistoricalDefectCorrelation[]`
- `reasoningResults`: `EngineeringReasoningResult[]`
- `advisoryNotice`: string

## 3. Synchronized State Machine
- `selectedFeatureId`: ID of active geometric feature selected in 3D canvas or finding list.
- `selectedFindingId`: ID of active DFM finding selected in finding list or spatial 3D pin.
- `activeWorkspaceTab`: `'reasoning'` | `'cost'` | `'evidence'`.
