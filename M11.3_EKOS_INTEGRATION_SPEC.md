# M11.3 EKOS Integration Specification

## 1. Traceability Graph Lineage
Reasoning results and recommendations project into the EKOS Enterprise Knowledge & Operations Structure:

```text
Drawing Revision (DRAWING)
        ↓ CONSTRAINS
Geometric Feature (FEATURE)
        ↓ DERIVED_FROM
DFM Finding (NCR / DEFECT_RISK)
        ↓ DERIVED_FROM [EkosProvenanceType: AI_INFERRED]
Engineering Reasoning Result (TRIAL_OBSERVATION)
        ↓ GENERATES
Advisory Recommendation (RECOMMENDATION)
        ↓ RESOLVED_BY
Human Review Decision (EXPLICIT_HUMAN)
```

## 2. Graph Node & Edge Properties
- `sourceEntityType`: `EkosEntityType.NCR` (DFM Finding)
- `targetEntityType`: `EkosEntityType.TRIAL_OBSERVATION` (Reasoning Result)
- `relationType`: `EkosRelationType.DERIVED_FROM`
- `provenanceType`: `EkosProvenanceType.AI_INFERRED`
- `confidence`: Populated with deterministic confidence score (0.0 to 1.0)
