# M9.4 — Model Rollback Specification
## Rollback Lineage, State Re-activation & Audit Trails
**Milestone:** `M9.4`  
**Status:** **AUTHORITATIVE**

---

## 1. Rollback Execution Protocol

1. **Active Validation:** Target model must be currently `ACTIVE`.
2. **Lineage Discovery:** Queries the most recently retired model for the same `(tenantId, capability)` ordered by `retiredAt DESC`.
3. **Fail-Closed Condition:** If no previous retired model exists, throws `BadRequestException` without mutating state.
4. **Atomic Switch:**
   - Active model transitioned: `ACTIVE -> ROLLED_BACK` (`rolledBackAt = now()`, `rollbackReason = dto.rollbackReason`).
   - Previous retired model transitioned: `RETIRED -> ACTIVE` (`activatedAt = now()`, `retiredAt = null`).
5. **Audit Trail:** Emits `G14_MODEL_ROLLED_BACK` audit log.
