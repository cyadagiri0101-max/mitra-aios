# M11.4 Accessibility Specification

## 1. Multi-Modal Accessibility
- **Non-3D Fallback Mode**: `CadCanvasFallbackSummary` provides an accessible, keyboard-navigable tabular breakdown of all features and findings.
- **ARIA & Keyboard Navigation**: Full keyboard navigation across finding lists, 3D viewport preset buttons, reasoning step drawers, and review decision modals.
- **Contrast & Hierarchy**: WCAG AA compliant text contrast ratios across all panels.
