## 1. Validated Failure Scenarios

| Scenario | Injected Condition | Observed System Response | Status |
|:---|:---|:---|:---:|
| **Untrained Model** | Model is null or weights incomplete | Returns deterministic heuristic forecast (`FALLBACK_UNTRAINED_MODEL`) | **PASS** |
| **Insufficient Data** | Historical snapshots $< 5$ | Rejects training with `BadRequestException (400)` | **PASS** |
| **Non-existent Machine** | Invalid UUID or cross-tenant ID | Returns `NotFoundException (404)` | **PASS** |
| **Missing Tenant Context** | Missing or null tenant header | Throws `ForbiddenException (403)` | **PASS** |
| **Unsupported Version** | Version $\neq$ `G14_CAPACITY_V1` | Throws `BadRequestException (400)` | **PASS** |
