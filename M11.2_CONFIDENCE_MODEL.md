## 1. Confidence Formula

$$\text{Confidence} = \min\Big(1.0, \, 0.50 + 0.05 \times N_{\text{evidence}}\Big) \times \text{Similarity}$$

- If $N_{\text{evidence}} = 0 \implies \text{Confidence} = 0.0$ (`NO_EVIDENCE`).
- If $\text{Confidence} \ge 0.85 \implies \text{STRONG_ASSOCIATION}$.
- If $0.65 \le \text{Confidence} < 0.85 \implies \text{MODERATE_ASSOCIATION}$.
- If $\text{Confidence} < 0.65 \implies \text{WEAK_ASSOCIATION}$.
