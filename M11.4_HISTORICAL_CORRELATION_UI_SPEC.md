# M11.4 Historical Correlation UI Specification

## 1. M11.2 Historical Defect Integration
Displays correlated quality events (NCRs, mold trials, CAPAs) linked to geometric features and DFM findings.

## 2. Correlation vs Causation Boundary
- UI explicitly distinguishes empirical correlation from direct causation.
- Displays: Defect type (e.g. `SHORT_SHOT`, `SINK_MARK`, `CORE_PIN_BEND`), similarity score (e.g. 0.92), confidence score (e.g. 0.94), historical occurrences count (e.g. 8 occurrences), and source QMS inspection records.
