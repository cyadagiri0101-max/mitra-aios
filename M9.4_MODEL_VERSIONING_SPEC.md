# M9.4 — Model Versioning Specification
## Immutable Version Identifiers & Lineage Preservation
**Milestone:** `M9.4`  
**Status:** **AUTHORITATIVE**

---

## 1. Versioning Invariants

1. **Immutability:** Once registered in `g14_model_registry`, model weights, intercepts, metrics, and hashes are strictly immutable.
2. **Version Format:** Standard version naming convention:
   - Delay Models: `G14_DELAY_RIDGE_V{N}_{TIMESTAMP}`
   - Capacity Models: `G14_CAPACITY_RIDGE_V{N}_{TIMESTAMP}`
3. **Lineage Preservation:** Re-training generates a new distinct registry row without modifying previous version artifacts.
