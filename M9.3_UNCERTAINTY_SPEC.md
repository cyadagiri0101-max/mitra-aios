# M9.3 — Capacity Uncertainty Specification
## Residual Prediction Intervals for Deficit Hours
**Milestone:** `M9.3`  
**Method:** `RESIDUAL_PREDICTION_INTERVAL`  
**Status:** **AUTHORITATIVE**

---

## 1. Uncertainty Quantification

1. **Validation Residual Variance:**
   $$\sigma = \sqrt{\frac{1}{n_{\text{val}}} \sum_{i=1}^{n_{\text{val}}} (y_i - \hat{y}_i)^2}$$
2. **Prediction Bounds ($1 - \alpha$ Confidence):**
   - 90% Confidence ($z = 1.645$): $[\max(0, \hat{y} - 1.645\sigma), \hat{y} + 1.645\sigma]$
   - 95% Confidence ($z = 1.960$): $[\max(0, \hat{y} - 1.960\sigma), \hat{y} + 1.960\sigma]$
   - 99% Confidence ($z = 2.576$): $[\max(0, \hat{y} - 2.576\sigma), \hat{y} + 2.576\sigma]$
3. **Data Quality Status:**
   Flagged as `DEGRADED` if machine has 0 available hours in horizon, or `INSUFFICIENT` if operates in heuristic fallback mode.
