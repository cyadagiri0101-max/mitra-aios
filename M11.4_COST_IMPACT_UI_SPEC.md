# M11.4 Cost & Impact UI Specification

## 1. Governed Cost Synthesis Table
Displays 6 cost categories:
1. `Material`: Quantity, unit rate, calculated cost, status.
2. `Machining`: EDM spark erosion, CNC cavity rework.
3. `Tooling`: Core pin and mold insert modifications.
4. `Quality`: CMM first article inspection standard.
5. `Schedule`: Machine overhead and shot cooling cycle delay.
6. `Rework`: Bench polishing and fitment calibration.

## 2. 3-Point Uncertainty Range
Displays:
- `Low`: $\text{Expected} \times 0.85$
- `Expected`: Deterministic sum of configured rate components
- `High`: $\text{Expected} \times 1.25$

## 3. Unconfigured Rates Fail-Safe
If a cost rate is not configured in `engineering_cost_configurations`, the UI displays `COST_NOT_CONFIGURED` (`UNAVAILABLE`) with `null` values. Fabricated zeros are strictly prohibited.
