# M11.5 3D Resource Governance Specification

## 1. WebGL Resource Management
- Meshes, box geometries, sphere geometries, and standard materials are managed within React Three Fiber declarative component lifecycle.
- When an engineer navigates away from the review workspace or switches drawing revisions, WebGL contexts and scene graphs unmount cleanly without progressive GPU memory growth.
- Fallback summary (`CadCanvasFallbackSummary`) provides a lightweight, non-WebGL alternative.
