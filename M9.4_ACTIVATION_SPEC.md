# M9.4 — Model Activation Specification
## Single Active Champion Invariant & Atomic State Transitions
**Milestone:** `M9.4`  
**Status:** **AUTHORITATIVE**

---

## 1. Single Champion Invariant

- At most **one ACTIVE model** per `(tenant_id, capability)` is permitted at any given time.
- Enforced at both:
  1. Database level via unique partial index `UQ_g14_model_registry_active_champion`.
  2. Service level inside `G14ModelRegistryService.activateModel()` using `SERIALIZABLE` database transactions.

---

## 2. Atomic Transition Execution

1. Target model status verified as `APPROVED`.
2. Existing active champion transitioned: `ACTIVE -> RETIRED` (`retiredAt = now()`).
3. Target model transitioned: `APPROVED -> ACTIVE` (`activatedAt = now()`).
4. Both updates committed atomically; rollback transaction on any failure.
