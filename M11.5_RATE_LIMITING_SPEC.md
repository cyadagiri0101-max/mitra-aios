# M11.5 Rate Limiting Specification

## 1. Configured Rate Limits
Centralized in `src/common/config/throttle.config.ts`:
- `ENGINEERING_REASONING_THROTTLE`: 30 requests / 60 seconds (prevents CPU exhaustion on 9-step reasoning pipelines).
- `ENGINEERING_EVALUATION_THROTTLE`: 20 requests / 60 seconds (geometry extraction & DFM evaluation).
- `ENGINEERING_REVIEW_THROTTLE`: 60 requests / 60 seconds (human review decision submissions).
- `ENGINEERING_WORKSPACE_THROTTLE`: 120 requests / 60 seconds (workspace aggregated view queries).

## 2. Guard Integration
Applied via `@Throttle({ default: ... })` and `ThrottlerGuard` across `GeometryDfmController` and `EngineeringReasoningController`.
