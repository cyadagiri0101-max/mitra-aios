## 1. Baseline Infrastructure Inventory

- **M7.2 Knowledge Chunks:**
  - Table: `knowledge_chunks`
  - Total Chunks: 3,474 indexed chunks with deterministic UUIDs, SHA-256 `contentHash`, structured metadata, and preserved Markdown table headers.
  - Granular coordinates: `projectNumber`, `projectPrefix`, `customer`, `machine`, `material`, `revision`, `authorityStatus`, `sourceFile`, `sourceSheet`, `sourceRow`, `sourcePage`.
- **M7.2 Knowledge Embeddings:**
  - Table: `knowledge_embeddings`
  - Total Vectors: 3,474 local 768-dimensional vectors generated via `nomic-embed-text`.
  - Column: `embedding` with pgvector cosine distance support (`<=>`).
- **AI & Embedding Infrastructure:**
  - `EmbeddingService` (`src/modules/ai/services/embedding.service.ts`): generates 768d vectors with offline deterministic fallback.
  - `OllamaProvider` (`src/modules/ai/providers/ollama.provider.ts`): communicates with local Ollama (`http://localhost:11434`).
  - `VectorSearchService` (`src/modules/ai/services/vector-search.service.ts`): provides vector search and trigram fallback.
