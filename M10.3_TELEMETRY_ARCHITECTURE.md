## 1. Pipeline Architecture

```
[Shop-Floor Sensors / PLC / Operators]
                  │
                  ▼
[ManufacturingTelemetryService]
  • Range & Unit Normalization
  • Idempotency & Duplicate Filtering
  • Late / Quarantined Classification
                  │
                  ├──► [manufacturing_signals (Authoritative MES DB)]
                  │
                  └──► [EKOS Lineage Projection]
                         • Node: TRIAL_OBSERVATION
                         • Edge: OBSERVED_IN -> MachineMaster / WorkOrder
```
