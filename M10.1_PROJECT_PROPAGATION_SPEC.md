# M10.1 — Project Propagation Specification
## Project-Centric Context Preservation in Graph Projections
**Milestone:** `M10.1`  
**Status:** **AUTHORITATIVE**

---

## 1. Project Scoping Invariant

- In alignment with `PROJECT_CONSTITUTION.md` Principle 1 ("Project-centric, not ERP-centric"), every graph node and edge carries an optional `project_id`.
- When an entity belongs to a project (e.g., Drawing `DWG-100` created inside Project `PRJ-50`), all child relations inherit and propagate the originating `project_id`.
- Graph queries can be strictly scoped by `projectId` to isolate single-project lineage graphs from global cross-project catalogs.
