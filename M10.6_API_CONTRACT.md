# M10.6 — API Contract Specification
## REST Endpoints for EKOS Intelligence & Context
**Milestone:** `M10.6`  
**Status:** **AUTHORITATIVE**

---

## 1. Endpoints

- `GET /api/ekos/context/project/:projectId`: Aggregate cross-domain enterprise context for a project.
- `POST /api/ekos/context/question`: Ask cross-domain evidence-grounded intelligence questions.
- `POST /api/ekos/context/search`: Governed enterprise search across canonical graph entities.
