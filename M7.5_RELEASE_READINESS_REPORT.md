## 3. Known Limitations & Documented Guardrails

1. **Local LLM Speed on CPU:** When running on non-GPU host CPUs, Phi-3 mini inference averages ~7–9 seconds. The deterministic grounded fallback synthesizer provides sub-10ms response times when ultra-low latency is required.
2. **Read-Only Scope:** Ingestion is unidirectional from the source vault into PostgreSQL/pgvector. Real-time authoring of new CAD/Excel files within the vault is managed externally.
3. **Historical Document Inclusion:** Superseded documents are strictly omitted by default to ensure design safety. Users must explicitly toggle `includeHistorical: true` to inspect obsolete revision history.
