# M11.3 Audit Specification

## 1. Emitted Audit Events
- `ENGINEERING_REASONING_GENERATED`: Logged when a 9-step reasoning pipeline completes.
- `ENGINEERING_RECOMMENDATION_ACCEPTED`: Logged on human approval.
- `ENGINEERING_RECOMMENDATION_MODIFIED`: Logged when modified by engineer.
- `ENGINEERING_RECOMMENDATION_REJECTED`: Logged when rejected with notes.
- `ENGINEERING_RECOMMENDATION_CANCELLED`: Logged on cancellation.
- `COST_CONFIGURATION_CREATED`: Logged when a new cost rate is defined.
- `COST_CONFIGURATION_UPDATED`: Logged when a rate is modified.
- `COST_CONFIGURATION_DELETED`: Logged when a rate is removed.
