# M11.4 Responsive UI Specification

## 1. Multi-Device Layout Support
- **Desktop Engineering Workstations (1920x1080+)**: 3-column split view (3D Canvas 2 cols, Findings 1 col), expanded reasoning and cost panels.
- **Laptops (1366x768 to 1600x900)**: Stacked 3D canvas and collapsible finding sidebar.
- **Tablets (768x1024)**: Touch-enabled canvas orbit controls and tabbed deep-dive panels.
