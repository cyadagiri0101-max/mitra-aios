## 1. Uncertainty Quantification Protocol

1. **Residual Variance ($\sigma^2$):** Computed from out-of-sample validation residuals:
   $$\sigma = \sqrt{\frac{1}{n_{\text{val}}} \sum_{i=1}^{n_{\text{val}}} (y_i - \hat{y}_i)^2}$$
2. **Prediction Intervals ($1 - \alpha$ Confidence):**
   - 90% Interval ($z = 1.645$): $[\max(0, \hat{y} - 1.645\sigma), \hat{y} + 1.645\sigma]$
   - 95% Interval ($z = 1.960$): $[\max(0, \hat{y} - 1.960\sigma), \hat{y} + 1.960\sigma]$
   - 99% Interval ($z = 2.576$): $[\max(0, \hat{y} - 2.576\sigma), \hat{y} + 2.576\sigma]$
3. **Distinction from Confidence Interval:**
   Prediction intervals capture total forecast uncertainty for individual project outcomes (model parameter variance + observation variance), avoiding overconfident point predictions.
