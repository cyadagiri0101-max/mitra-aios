# Commercial Domain — End-to-End Validation

**Date:** 2026-07-28
**Workflow:** Customer → Contact → RFQ → Review → Quotation → Send → Accept → Project

---

## Workflow Map

```
Customer         ──►  Customer created (POST /commercial/customers)
  │
  ▼
Contact          ──►  Contact added (POST /commercial/customers/:id/contacts)
  │
  ▼
RFQ (Enquiry)    ──►  Enquiry created (POST /commercial/enquiries)
  │
  ▼
Review RFQ       ──►  Enquiry submitted → reviewed (POST /:id/submit → /:id/review)
  │
  ▼
Quotation        ──►  Quotation created from RFQ (POST /commercial/quotations)
  │
  ▼
Send             ──►  Quotation sent (POST /commercial/quotations/:id/send)
  │
  ▼
Accept           ──►  Quotation accepted (POST /commercial/quotations/:id/accept)
  │
  ▼
Automatic        ──►  Project created (via ProjectService), quotation linked
Project
```
