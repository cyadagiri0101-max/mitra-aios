## Operational Modes, Health Probing & Graceful Degradation Protocol
**Milestone:** `M7.4`

---

## 1. Readiness State Machine

The engineering grounding pipeline detects five distinct operational modes:

| Mode | Ollama Status | Model Status | Pipeline Behavior |
| :--- | :---: | :---: | :--- |
| **`LIVE_PHI3_INFERENCE`** | Online | `phi3` Ready | Live local LLM inference with strict grounding system prompt. |
| **`MODEL_NOT_FOUND`** | Online | `phi3` Missing | Deterministic grounded synthesis fallback; reports readiness warning. |
| **`OLLAMA_OFFLINE`** | Offline | N/A | Offline deterministic grounded synthesis; zero cloud calls. |
| **`INFERENCE_TIMEOUT`** | Online | Timeout ($>45\text{s}$) | Gracefully aborts; returns safe grounded fallback with error telemetry. |
| **`MALFORMED_OUTPUT`** | Online | Parse Error | Citation validator rejects invalid output; falls back safely. |

---

## 2. Hard Anti-Fabrication Invariants
1. **Never fabricate LLM execution:** Telemetry explicitly reports `modelUsed`, `durationMs`, and whether live inference or deterministic fallback ran.
2. **Never call external cloud APIs:** All execution is strictly air-gapped on local infrastructure.
