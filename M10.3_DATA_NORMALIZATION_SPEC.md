## 1. Normalization Matrix

| Signal Type | Standard Unit | Valid Range | Anomaly / Quarantine Criteria |
|:---|:---|:---|:---|
| `CYCLE_TIME` | `seconds (s)` | $[0.1, 86400]$ | Value $< 0$ or $> 86400$ |
| `TEMPERATURE` | `Celsius (°C)`| $[-40, 1500]$ | Value $> 1500$ |
| `RPM` | `rev/min` | $[0, 60000]$ | Value $< 0$ or $> 60000$ |
| `POWER_KW` | `kW` | $[0, 1000]$ | Value $< 0$ or $> 1000$ |
