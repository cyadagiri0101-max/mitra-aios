# M11.0 — Architectural Debt Audit
## Classification of Technical, Migration, and Test Debt
**Milestone:** `M11.0`  
**Status:** **AUTHORITATIVE**

---

## 1. Debt Classification

1. **Entity & DTO Synchronization:**
   - Some legacy commercial endpoints still utilize broad generic `any` metadata dictionaries instead of strongly typed class-validator schemas.
2. **Frontend Graph Visualizer:**
   - EKOS lineage endpoints provide complete JSON graph payloads; the frontend requires a dedicated interactive 2.5D/3D Node Graph Explorer for deeper visual drill-down.
3. **Migration Footprint:**
   - 53 sequential migrations currently exist. For enterprise on-prem packaging, a consolidated baseline squash script is recommended for fresh installations while preserving existing migration history.
4. **Local LLM Runtime Fallback:**
   - G13 Cited RAG relies on Ollama with Mock fallback; a formal local ONNX/WebAssembly edge inference runtime adapter would improve air-gapped performance.
