# M11.3 Reasoning Data Model Specification

## 1. EngineeringReasoningResult Entity (`engineering_reasoning_results`)
- `id`: UUID Primary Key
- `tenant_id`: UUID (fail-closed tenant isolation)
- `project_id`: UUID
- `drawing_id`: UUID
- `drawing_revision`: VARCHAR(50) (e.g. 'Rev A')
- `source_finding_id`: UUID (foreign link to `dfm_findings`)
- `reasoning_version`: VARCHAR(20) (default '1.0')
- `status`: `GENERATED`, `UNDER_REVIEW`, `ACCEPTED`, `MODIFIED`, `REJECTED`, `SUPERSEDED`, `CANCELLED`
- `evidence_hash`: VARCHAR(64) SHA-256 idempotency hash
- `steps`: JSONB array of `ReasoningStep`
- `evidence`: JSONB array of `EvidenceItem`
- `assumptions`: JSONB array of `Assumption`
- `constraints`: JSONB array of `EngineeringConstraint`
- `contradictions`: JSONB array of `Contradiction`
- `impacts`: JSONB array of `EngineeringImpact`
- `cost_summary`: JSONB object of `CostSummary`
- `recommendation`: JSONB object of `Recommendation`
- `confidence_score`: DECIMAL(5,4)
- `confidence_factors`: JSONB object of `ConfidenceFactors`
- `provenance`: JSONB metadata
- `reviewed_by`: UUID
- `reviewed_at`: TIMESTAMPTZ
- `decision_notes`: TEXT

## 2. EngineeringCostConfiguration Entity (`engineering_cost_configurations`)
- `id`: UUID Primary Key
- `tenant_id`: UUID
- `rate_type`: `MACHINE_HOUR`, `MATERIAL_UNIT`, `LABOR_HOUR`, `TOOLING_SETUP`, `INSPECTION_HOUR`, `REWORK_HOUR`, `SETUP_HOUR`
- `rate_name`: VARCHAR(100)
- `work_center_id`: UUID (nullable)
- `machine_id`: UUID (nullable)
- `material_id`: UUID (nullable)
- `operation_id`: UUID (nullable)
- `rate_value`: DECIMAL(18,4)
- `currency`: VARCHAR(10) (default 'INR')
- `uom`: VARCHAR(20) (default 'HOUR')
- `status`: `ACTIVE`, `INACTIVE`, `DEPRECATED`
