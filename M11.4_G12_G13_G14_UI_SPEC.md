# M11.4 G12, G13, G14 UI Specification

## 1. G12 Knowledge Promotion Experience
- Displays `G12 Knowledge Candidate: ELIGIBLE`.
- Requires human acceptance before knowledge candidate submission.
- Zero autonomous unverified publication.

## 2. G13 Authoritative Citation Experience
- Citation pills display authoritative source ID, revision, and provenance.
- Clicking citation resolves directly to verified source record.

## 3. G14 Advisory Predictive Context
- Visualizes predictive signals: DFM Risk Index, Defect Recurrence Probability, and Cycle Time Overhead.
- Clearly labeled as `ADVISORY PREDICTIVE CONTEXT`.
