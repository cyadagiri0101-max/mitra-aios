# M10.3 — Event Correlation Specification
## Hierarchical Multi-Entity Manufacturing Signal Correlation
**Milestone:** `M10.3`  
**Status:** **AUTHORITATIVE**

---

## 1. Correlation Hierarchy

```
Tenant
  └── Project
        └── Work Order
              └── Operation
                    └── Machine / Sensor
```
Incoming signals carry explicit `workOrderId` or `machineId`, which automatically propagates parent `projectId` without heuristics.
