# M10.1 — EKOS Graph REST API Contract Specification
## Endpoint Definitions, Request / Response Schemas
**Milestone:** `M10.1`  
**Status:** **AUTHORITATIVE**

---

## 1. Endpoints Ledger

- `POST /api/ekos/graph/nodes`: Idempotently register or update an entity node.
- `POST /api/ekos/graph/edges`: Record or update a semantic lineage edge.
- `GET /api/ekos/graph/lineage/:entityType/:entityId`: Traverse upstream, downstream, or bidirectional lineage graph.
- `GET /api/ekos/graph/impact/:entityType/:entityId`: Evaluate downstream blast-radius impact.
- `GET /api/ekos/graph/integrity`: Run graph anomaly and cycle detection report.
