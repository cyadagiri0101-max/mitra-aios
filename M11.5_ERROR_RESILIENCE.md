# M11.5 Error Resilience Specification

## 1. Resilience Patterns
- **Database Timeouts / Connection Limits**: Handled gracefully with retry and structured error responses.
- **Missing Cost Rates**: Handled cleanly by returning `COST_NOT_CONFIGURED` (`UNAVAILABLE`) with `null` values; no zero fabrication.
- **3D Render Errors**: Caught by React Error Boundary; renders structured 2D tabular interface (`CadCanvasFallbackSummary`).
- **Dependency Outages (EKOS/G12/G13/G14)**: Non-blocking degraded mode ensures core engineering review remains accessible.
