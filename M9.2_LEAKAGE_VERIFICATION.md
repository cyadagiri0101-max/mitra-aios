## 1. Leakage Verification Results

1. **Prediction Cutoff:** `G14DelayInferenceService` extracts input features using strictly historical observation windows ($\le \text{predictionCutoff}$).
2. **Post-Cutoff Sanitization:** Any post-cutoff events are excluded from the 20-dimensional feature vector.
3. **Target Isolation:** Model weights are learned exclusively on $(X_{\text{train}}, y_{\text{train}})$ with $y_{\text{train}}$ observed strictly after feature observation cutoffs.
4. **Out-of-Time Testing:** Zero random shuffle in cross-validation; strictly chronological train/validation/test ordering prevents backward leakage.
