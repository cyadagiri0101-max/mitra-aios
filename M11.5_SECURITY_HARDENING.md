# M11.5 Security Hardening Document

## 1. Security Architecture
All engineering endpoints across `GeometryDfmController` and `EngineeringReasoningController` are secured by:
- `JwtAuthGuard`: Enforces cryptographically verified JWT bearer tokens.
- `RolesGuard`: Restricts operations to authorized enterprise roles (`ADMIN`, `ENGINEERING`, `QUALITY`, `PLANNING`).
- `ThrottlerGuard`: Protects against brute-force flooding and resource exhaustion.

## 2. Fail-Closed Tenant Isolation
- Foreign tenant IDs passed to endpoints return 0 items or `404 Not Found`.
- Cross-tenant review injection attempts fail immediately.
- Provenance hashes and audit trails maintain strict tenant partitioning.
