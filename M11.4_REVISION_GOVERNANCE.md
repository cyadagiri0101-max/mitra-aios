# M11.4 Revision Governance Specification

## 1. Revision Safety Top Banner
Implemented in `src/components/Engineering/RevisionSafetyBanner.tsx`.

## 2. Invariants
- Active Drawing Revision must match the Analysis Revision (e.g. `Active: Rev B`, `Analysis: Rev B`).
- If an older analysis result (e.g. Rev A) is loaded against an updated drawing model (Rev B), the banner immediately alerts:
  `REVISION MISMATCH DETECTED: Stale analysis cannot be applied to newer CAD revision.`
- Ensures engineers never make decisions based on outdated geometric baselines.
