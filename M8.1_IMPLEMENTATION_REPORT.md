## 1. Baseline Discovered

Prior to M8.1, the `KnowledgeArticle` entity (`src/modules/knowledge/entities/knowledgearticle.entity.ts`) was a basic schema storing raw article content with basic author and category metadata. It lacked versioning, revision parentage, superseding pointers, domain project/decision associations, rejection tracking, and expiry dates.

## 3. Database Migration Specification

- **Migration File:** `src/database/migrations/1700000000044-M8KnowledgeLifecycle.ts`
- **Class Name:** `M8KnowledgeLifecycle1700000000044`
- **Migration Actions:**
  1. `ALTER TABLE "knowledge_articles"` adding `version`, `is_latest`, `parent_article_id`, `superseded_by_id`, `project_id`, `decision_id`, `rejection_reason`, `expires_at`.
  2. Updated check constraint `knowledge_articles_status_check` to include `REJECTED`, `SUPERSEDED`, `EXPIRED`.
  3. Added foreign key constraints:
     - `FK_knowledge_articles_parent` $\rightarrow$ `knowledge_articles(id) ON DELETE SET NULL`
     - `FK_knowledge_articles_superseded_by` $\rightarrow$ `knowledge_articles(id) ON DELETE SET NULL`
     - `FK_knowledge_articles_project` $\rightarrow$ `projects(id) ON DELETE SET NULL`
     - `FK_knowledge_articles_decision` $\rightarrow$ `engineering_decisions(id) ON DELETE SET NULL`
  4. Added indexes:
     - `IDX_knowledge_articles_tnt_status` (`tenant_id`, `status`, `deleted_at`)
     - `IDX_knowledge_articles_tnt_is_latest` (`tenant_id`, `is_latest`, `deleted_at`)
     - `IDX_knowledge_articles_tnt_project` (`tenant_id`, `project_id`, `deleted_at`)
     - `IDX_knowledge_articles_tnt_decision` (`tenant_id`, `decision_id`, `deleted_at`)
     - `IDX_knowledge_articles_parent` (`parent_article_id`)
