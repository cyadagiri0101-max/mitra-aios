## 1. Verified Graph Invariants

| Invariant / Check | Detection Mechanism | Resolution |
|:---|:---|:---|
| **Dangling Edge** | Target or Source Node ID does not exist in `ekos_graph_nodes` | Reported in integrity violations; removed or re-synced |
| **Duplicate Edge** | Multiple active edges with identical `(source, target, relation)` | Reported and deduplicated |
| **Cross-Tenant Leak** | Node or Edge tenant ID does not match calling tenant | Blocked fail-closed; reported as security violation |
| **Forbidden Cycle** | DFS traversal on `DERIVED_FROM` detects loop in recursion stack | Reported as `FORBIDDEN_CYCLE`; strict DAG enforced |
| **Orphan Node** | Node has 0 incoming and 0 outgoing edges | Reported in integrity summary |
