# M11.3 Cost Configuration Specification

## 1. Multi-Tenant Cost Rate Model
Cost configurations are isolated by `tenantId` and support granular rate resolution:
- Default tenant rate
- Work Center specific rate (`workCenterId`)
- Machine specific rate (`machineId`)
- Material specific rate (`materialId`)
- Operation specific rate (`operationId`)

## 2. Rate Types
- `MACHINE_HOUR` (e.g. CNC 5-Axis, EDM, Lathe)
- `MATERIAL_UNIT` (e.g. INR per KG polymer resin / steel billet)
- `LABOR_HOUR` (e.g. Shop floor operator rate)
- `TOOLING_SETUP` (e.g. Toolmaker setup rate)
- `INSPECTION_HOUR` (e.g. CMM Metrology rate)
- `REWORK_HOUR` (e.g. Bench deburring and rectification)
- `SETUP_HOUR` (e.g. Mold changeover and machine setup)
