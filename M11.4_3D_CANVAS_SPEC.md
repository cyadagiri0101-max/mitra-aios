# M11.4 3D Canvas Specification

## 1. Stack and Capabilities
- **Renderer**: WebGL via `@react-three/fiber` and Three.js.
- **Controls**: `OrbitControls` with smooth inertia damping (`dampingFactor: 0.05`), rotate, pan, and zoom.
- **View Presets**:
  - `ISO`: `[4, 3, 4]`
  - `FRONT`: `[0, 0, 5]`
  - `TOP`: `[0, 5, 0]`
  - `RIGHT`: `[5, 0, 0]`
- **Rendering Modes**:
  - Solid Shaded (Metallic roughness material)
  - Wireframe (`isWireframe: true`)
  - Translucent X-Ray (`isTransparent: true`, opacity: 0.35)

## 2. Spatial Overlays
- **DFM Spatial Pins**: Emissive spheres anchored at geometric feature coordinates.
  - Critical: `#FF4D4D` pulsating pin
  - Warning: `#FFA500` pin
  - Verified: `#64FFDA` highlight
- **Feature Mesh Click Interaction**: Raycasting click selection triggers state synchronization across DFM findings, reasoning steps, and evidence items.

## 3. Graceful Fallback Strategy
If WebGL context fails to initialize or throws:
- Error boundary catches error
- Activates `CadCanvasFallbackSummary`
- Renders structured 2D tabular engineering interface
- Review workflow remains 100% unblocked and functional
