# M10.5 — API Contract Specification
## REST Endpoints for Compliance Packages
**Milestone:** `M10.5`  
**Status:** **AUTHORITATIVE**

---

## 1. Endpoints

- `POST /api/compliance/packages`: Generate new compliance audit package.
- `GET /api/compliance/packages/:id`: Retrieve package by ID.
- `GET /api/compliance/packages/:id/export`: Export structured audit manifest and evidence items.
- `GET /api/compliance/packages/:id/integrity`: Verify cryptographic SHA-256 package integrity.
