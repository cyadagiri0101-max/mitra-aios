**Milestone:** `M10.4`

## 1. Closed-Loop Flow

```
[Shop-Floor Observations / Telemetry]
                  │
                  ▼
[Operational State Derivation & Anomaly Detection]
                  │
                  ▼
[Advisory Recommendation Generation (Status: REVIEW)]
                  │
                  ▼
[Human Review & Governance: ACCEPT / MODIFY / REJECT / CANCEL]
                  │
                  ▼
[Authoritative Action Executed by Plant Manager / Engineer]
```
