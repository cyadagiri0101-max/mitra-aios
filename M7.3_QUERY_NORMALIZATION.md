## Engineering Query Normalizer & Intent Detection Architecture
**Milestone:** `M7.3`  
**Status:** Certified Specification  
**Module:** `src/modules/engineering-library/retrieval`

---

## 1. Normalization Pipeline

1. **Text Cleansing:**
   - Strips illegal punctuation while preserving engineering hyphenation (e.g. `BM-454`), dots in machine names (`Dr. Boy`), and dimensions (`1230 x 135 x 40`).
   - Normalizes multiple spaces and trims leading/trailing whitespace.

2. **Regex Filter Extraction:**
   - **Project Identifiers:** Detects patterns `(BM|IM|TC|MM|PL|PRJ)[-_]?\d+` (e.g. `BM454`, `IM102`, `TC001`).
   - **Revisions:** Detects `Rev[-_\s]?[A-Z0-9]+` (e.g. `RevA`, `Rev B`).
   - **Customers:** Matches recognized tooling customers (`Veedol`, `ALPLA`, `Dabur`, `Castrol`, `Tata`, `Maruti`, `Mahindra`).
   - **Machines:** Matches tooling machines (`SPEEDEX`, `SEB101`, `Engel`, `Ferromatik`, `Dr. Boy`, `Windsor`, `Arburg`).
   - **Materials:** Matches polymer grades and tool steels (`HDPE`, `PP`, `PET`, `ALUMINIUM`, `HOKOTOL`, `ALUMOLD`, `P20`, `EN24`, `EN31`, `STAVAX`).
   - **Entity Type Intent:** Detects domain intent tokens:
     - `BOM_PART`: `bom`, `part list`, `insert`, `cutting size`, `steel grade`
     - `CYCLE_TIME`: `cycle time`, `ct`, `cycle seconds`, `speedex cycle`
     - `PROCESS_PLAN`: `process`, `planning`, `sequence`, `operation`, `step`, `duration`
     - `PROJECT`: `mold`, `mould`, `project`, `cavitation`, `tooling`
     - `PRODUCT`: `bottle`, `volume`, `overflow`, `container shape`
