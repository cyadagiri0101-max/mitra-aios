## 1. Version Governance Rules

1. **Explicit Tagging:** Every feature extraction request and persisted snapshot records `featureVersion: 'G14_FEATURES_V1'`.
2. **Unsupported Version Rejection:** Requests with unknown or deprecated versions are rejected with `BadRequestException (400)`.
3. **Evolution Invariant:** Any future modification to vector dimensions, scaling constants, or feature family definitions will require a distinct version identifier (e.g. `G14_FEATURES_V2`) without mutating existing `G14_FEATURES_V1` snapshots.
