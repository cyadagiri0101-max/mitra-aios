## 1. Registry API Endpoints

- `GET /api/predictive/models` (Query parameters: `capability`, `status`, `modelVersion`)
- `GET /api/predictive/models/active/:capability`
- `GET /api/predictive/models/:id`
- `POST /api/predictive/models/:id/evaluate`
- `POST /api/predictive/models/:id/request-approval`
- `POST /api/predictive/models/:id/approve`
- `POST /api/predictive/models/:id/reject`
- `POST /api/predictive/models/:id/activate`
- `POST /api/predictive/models/:id/retire`
- `POST /api/predictive/models/:id/rollback`
