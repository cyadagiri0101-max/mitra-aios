# M11.4 EKOS Lineage UI Specification

## 1. Multi-Hop Lineage Hierarchy
Renders the complete end-to-end traceability tree:
```
RFQ / Customer Spec
  └── Drawing TOOL-2026-X (Rev B)
        └── Geometric Feature (FEAT-WALL-01)
              └── DFM Finding (FIND-DFM-WALL-001)
                    └── Historical Defect Correlation (SHORT_SHOT)
                          └── Engineering Reasoning Result (REAS-01)
                                └── Governed Cost Synthesis
                                      └── Advisory Recommendation (REC-01)
                                            └── Human Decision Record (ACCEPTED)
```

## 2. Security & Authority
Traversals strictly enforce tenant boundaries and RBAC permissions.
