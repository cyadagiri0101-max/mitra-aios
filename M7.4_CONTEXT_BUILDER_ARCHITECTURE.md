## 1. Architectural Overview

The `EngineeringContextBuilderService` sits between M7.3.1 Hybrid Retrieval and the local LLM inference engine. It performs three critical operations:
1. **Provenance Structuring:** Transforms normalized database and document chunks into numbered reference blocks (`[REF-1]`, `[REF-2]`, etc.) containing metadata headers.
2. **Deterministic Citation Registry Generation:** Produces an immutable, in-memory `Map<string, EngineeringCitationDto>` mapping each tag directly to its originating table, file, sheet, row, project, and authority status.
3. **Context Budget Enforcement:** Applies configurable chunk count limits (default 8) and character window boundaries (default 8,000 characters) without truncating tabular markdown structures mid-row.
