# M11.3 Manufacturing Context Specification

## 1. Manufacturing Data Integration
Where configured in the tenant database, the reasoning engine incorporates:
- `EngineeringWorkCenter`: Work center capabilities, tonnage limits, and hourly rate profiles.
- `EngineeringOperation`: Standard CNC milling, EDM, injection molding, and assembly operations.
- `EngineeringMaterial`: Resin flow rate, glass fiber reinforcement percentage, shrinkage coefficients.
- `EngineeringRouting`: Sequential manufacturing stages.
