# REPORTING.md

## Title
Standard Reporting Format

## Purpose
Defines the required structure for engineering responses and implementation summaries.

## Status
Active

## Version
0.1.0

## Author
Platform Engineering

## Last Updated
2026-07-09

## Required Response Sections
1. Understanding
2. Architecture Assessment
3. Implementation Plan
4. Production Implementation
5. Validation Summary
6. Architecture Review
7. Lifecycle State
8. Recommended Next Task

## Reporting Rules
- Report implementation facts and validation evidence.
- Do not report acceptance unless the user explicitly confirms it.
- Keep summaries concise and focused on the current task.
- Highlight risks, assumptions, and follow-up actions when relevant.
