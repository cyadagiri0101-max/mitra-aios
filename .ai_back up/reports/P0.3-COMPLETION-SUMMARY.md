## Technical Implementation

### SmartContextLoader Architecture
```
ContextProfile
├── discovery (8K token budget)
├── architecture (12K token budget)
├── implementation (16K token budget)
├── validation (10K token budget)
├── review (14K token budget)
├── governance (9K token budget)
└── release (11K token budget)

TokenAnalyzer
├── estimate_tokens(text) → int
├── estimate_cost(tokens, model) → float
└── format_tokens(count) → "2.7K"

SmartContextLoader
├── load_for_mode(mode) → context dict
├── _load_file(path) → data + metrics
├── _calculate_metrics(max_tokens) → metrics dict
├── _check_warnings(max_tokens) → warnings list
└── print_summary(context) → formatted output
```
