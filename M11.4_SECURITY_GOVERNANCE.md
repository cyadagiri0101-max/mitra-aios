# M11.4 Security & Governance Specification

## 1. Security Controls
- **JWT & RolesGuard**: All workspace endpoints protected with JWT bearer tokens and RBAC roles (`ADMIN`, `ENGINEERING`, `QUALITY`, `PLANNING`).
- **Fail-Closed Multi-Tenant Isolation**: Every query and mutation is strictly scoped to `tenantId`. Cross-tenant ID injections return empty sets or `404 Not Found`.
- **Authoritative Provenance**: Inferred suggestions are clearly separated from authoritative engineering records.
