# M9.5 — Recommendation Data Model Specification
## Schema, Attributes & Persistence Architecture
**Milestone:** `M9.5`  
**Status:** **AUTHORITATIVE**

---

## 1. Table Schema: `g14_leveling_recommendations`

- `id`: UUID PRIMARY KEY
- `tenant_id`: UUID NOT NULL
- `recommendation_type`: Enum (`SHIFT_OPERATION`, `REALLOCATE_MACHINE`, `ADJUST_MILESTONE_DATE`, `SPLIT_BATCH`, `ESCALATE_CAPACITY`)
- `capability`: VARCHAR(50) (`TIMELINE_LEVELING`)
- `project_id`: UUID NULL (Foreign key to `projects`)
- `milestone_id`: UUID NULL (Foreign key to `project_milestones`)
- `machine_id`: UUID NULL (Foreign key to `machine_masters`)
- `model_version`: VARCHAR(100) NOT NULL
- `risk_tier`: Enum (`LOW`, `MEDIUM`, `HIGH`, `CRITICAL`)
- `current_state`: JSONB NOT NULL
- `proposed_state`: JSONB NOT NULL
- `expected_benefit`: VARCHAR(255) NOT NULL
- `predicted_risk_before`: JSONB NOT NULL
- `predicted_risk_after`: JSONB NOT NULL
- `confidence`: NUMERIC(6, 4)
- `uncertainty_lower`: NUMERIC(10, 4)
- `uncertainty_upper`: NUMERIC(10, 4)
- `explanation`: JSONB NOT NULL
- `status`: Enum (`GENERATED`, `UNDER_REVIEW`, `ACCEPTED`, `MODIFIED`, `REJECTED`, `EXPIRED`, `APPLIED`, `CANCELLED`)
- `generated_at`, `expires_at`, `reviewed_by`, `reviewed_at`, `applied_by`, `applied_at`, `rejection_reason`, `modification_reason`, `cancellation_reason`.
