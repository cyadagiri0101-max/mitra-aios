# M11.4 Contradiction UI Specification

## 1. Contradiction States
- `NO_CONFLICT`: Empirical defect data and deterministic DFM rule evaluations agree.
- `CONFLICT_PRESENT`: Discrepancy detected between physical trial telemetry and theoretical calculations.
- `INSUFFICIENT_EVIDENCE`: Empirical sample size below statistical significance threshold.
- `REQUIRES_ENGINEERING_REVIEW`: Ambiguous boundary requiring human engineering intervention.

## 2. Visual Prominence
When a conflict is present, the card displays high-contrast red styling with exact conflicting source records (Source A vs Source B) and recommended review guidance.
