# M10.5 — Package Versioning Specification
## Immutable Package Snapshots & Sequential Versioning
**Milestone:** `M10.5`  
**Status:** **AUTHORITATIVE**

---

## 1. Versioning Protocol

- Packages are immutable upon generation.
- Re-generation for the same `(tenantId, projectId)` increments the `version` field.
- Previous package versions remain accessible for audit comparison.
