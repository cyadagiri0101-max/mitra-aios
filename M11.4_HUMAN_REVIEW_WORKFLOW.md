# M11.4 Human Review Workflow Specification

## 1. Governance State Machine
```
GENERATED
    ↓
UNDER_REVIEW
    ├── ACCEPTED  (with mandatory engineering justification)
    ├── MODIFIED  (with changed parameters and rationale)
    ├── REJECTED  (with rejection reason)
    └── CANCELLED / DEFERRED
```

## 2. Hard Governance Rule
- AI proposes advisory recommendations; human engineer reviews and decides.
- Original CAD geometry, drawings, BOM, routings, and machines are NEVER autonomously modified.
- Every review decision writes a cryptographically linked event to the audit ledger.
