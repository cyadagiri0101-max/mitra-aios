# M11.4 Reasoning UI Specification

## 1. 9-Step Reasoning Pipeline View
Implemented in `src/components/Engineering/EngineeringReasoningPanel.tsx`.

## 2. Steps Rendered
1. `Identify Geometric Finding`: Measurements and CAD solid tolerances.
2. `Retrieve Historical Evidence`: QMS NCRs, mold trials, and CAPA logs.
3. `Evaluate Feature Similarity`: Cosine topological vector convergence.
4. `Evaluate Material & Process Compatibility`: Resin rheology, shrinkage, cooling profile.
5. `Evaluate Manufacturing Implications`: Mold kinematics, core pin deflection, cycle delay.
6. `Evaluate Historical Defect Relevance`: Empirical root-cause alignment.
7. `Construct Engineering Assessment`: Cross-domain manufacturability and quality impact.
8. `Estimate Operational/Cost Impact`: Governed 6-component cost synthesis with 3-point uncertainty range.
9. `Generate Explainable Recommendation`: Governed advisory recommendation with full audit lineage.

## 3. Visual Artifacts
- Individual step expansion with transformation description
- Input evidence count and lineage status
- Individual step confidence gauges
