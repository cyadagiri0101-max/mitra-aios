# M9.3 — Capacity Feature Contract Specification
## G14_CAPACITY_V1 15-Dimensional Dense Feature Vector
**Milestone:** `M9.3`  
**Feature Version:** `G14_CAPACITY_V1`  
**Status:** **AUTHORITATIVE**

---

## 1. Feature Representation Ledger

| Dimension | Feature Name | Source Entity / Table | Description & Normalization |
|:---:|:---|:---|:---|
| $c_0$ | `available_machine_hours` | `MachineMaster` | Available hours in forecast horizon ($\frac{\text{horizonDays} \times 8.0}{240}$) |
| $c_1$ | `booked_demand_hours` | `MachineBooking` | Confirmed/in-use booking hours ($\frac{\text{hours}}{100}$) |
| $c_2$ | `scheduled_work_order_hours` | `WorkOrder` | Active work order load ($\frac{\text{hours}}{100}$) |
| $c_3$ | `total_demand_hours` | Combined | Sum of booked and work order hours ($\frac{\text{hours}}{200}$) |
| $c_4$ | `capacity_utilization_ratio` | Calculated | Ratio of total demand to available hours ($\min(3.0, \frac{\text{demand}}{\text{avail}})$) |
| $c_5$ | `historical_deficit_hours` | Calculated | Initial capacity deficit ($\frac{\max(0, \text{demand} - \text{avail})}{50}$) |
| $c_6$ | `queue_depth_work_orders` | `WorkOrder` | Active work orders assigned to machine |
| $c_7$ | `overdue_work_orders_count` | `WorkOrder` | Work orders past planned end date |
| $c_8$ | `active_bookings_count` | `MachineBooking` | Active booking slots count |
| $c_9$ | `maintenance_downtime_hours` | `MachineMaster` | Scheduled maintenance downtime ($\frac{\text{hours}}{50}$) |
| $c_{10}$ | `cost_per_hour_rate` | `MachineMaster` | Operating rate ($\frac{\text{cost}}{100}$) |
| $c_{11}$ | `is_active` | `MachineMaster` | Machine operational flag ($1.0$ or $0.0$) |
| $c_{12}$ | `near_term_due_load` | `WorkOrder` | Demand due within next 7 days ($\frac{\text{hours}}{50}$) |
| $c_{13}$ | `concurrent_project_count` | Distinct | Competing projects count |
| $c_{14}$ | `forecast_horizon_ratio` | Input | Forecast window scale factor ($\frac{\text{horizonDays}}{30}$) |
