# M11.1 — API Contract Specification
## REST Endpoints for Geometry Extraction & DFM Evaluation
**Milestone:** `M11.1`  
**Status:** **AUTHORITATIVE**

---

## 1. Endpoints

- `POST /api/engineering/geometry/extract`: Extract and normalize canonical geometric features from CAD/Drawing metadata.
- `GET /api/engineering/geometry/:drawingId`: Retrieve extracted features for a drawing revision.
- `POST /api/engineering/dfm/evaluate`: Run deterministic DFM rule evaluation against extracted features.
- `GET /api/engineering/dfm/findings/:drawingId`: Retrieve DFM findings for a drawing revision.
- `POST /api/engineering/dfm/findings/:id/review`: Governed human review of a DFM finding.
