**Milestone:** `M9.1`

## 1. Ground Truth Prediction Targets

1. **Target A — Project Delay (Continuous & Binary):**
   - `projectDelayDays`: Actual project finish date (or cumulative variance) minus target delivery date in days.
   - `isDelayed`: Boolean flag ($\text{projectDelayDays} > 0$).
2. **Target B — Milestone Variance (Multi-Output):**
   - `milestoneDelays`: Array of objects $\{\text{milestoneId}, \text{title}, \text{varianceDays}\}$.
3. **Target C — Capacity Risk Probability (Continuous $\in [0, 1]$):**
   - `capacityRiskScore`: $\min(1.0, \max(0.0, \frac{\text{capacityGapHours}}{\text{totalDemandHours}}))$.
