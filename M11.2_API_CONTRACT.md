# M11.2 — API Contract Specification
## REST Endpoints for Historical Defect Correlation
**Milestone:** `M11.2`  
**Status:** **AUTHORITATIVE**

---

## 1. Endpoints

- `POST /api/engineering/defects/correlate`: Trigger historical defect correlation for a drawing revision.
- `GET /api/engineering/dfm/findings/:id/history`: Retrieve historical defect context and citations for a specific finding.
- `GET /api/engineering/defects/correlations/:drawingId`: List all correlations for a drawing revision.
