# M11.3 Governed Cost Synthesis Specification

## 1. 6-Category Cost Component Model
1. **Material**: $\text{Volume/Mass} \times \text{Material Unit Rate}$
2. **Machining**: $\text{Machining Hours} \times \text{Machine Hour Rate}$
3. **Tooling**: $\text{Tooling Hours} \times \text{Tooling Setup Rate}$
4. **Quality**: $\text{Inspection Hours} \times \text{CMM/Inspection Rate}$
5. **Schedule**: $(\text{Cycle Time (s)} / 3600) \times \text{Machine Overhead Rate} \times \text{Lot Size}$
6. **Rework**: $\text{Rework Hours} \times \text{Rework Rate}$

## 2. Status Governance & Zero Fabrication Rule
- `KNOWN`: Rate exists in active tenant configuration and volume is verified.
- `ESTIMATED`: Standard engineering physics estimation with configured rate.
- `ASSUMED`: Unverified rate or quantity baseline.
- `COST_NOT_CONFIGURED` (`UNAVAILABLE`): If rate is not configured in the tenant database, cost calculation evaluates to `null` and the category is logged in `missingComponents`. The system NEVER fabricates rates.

## 3. 3-Point Uncertainty Range
- $\text{Expected Total} = \sum \text{Available Components}$
- $\text{Low Total} = \text{Expected Total} \times 0.85$
- $\text{High Total} = \text{Expected Total} \times 1.25$
