# M11.4 DFM Finding UI Specification

## 1. DFM Finding List Component
Implemented in `src/components/Engineering/DfmFindingListPanel.tsx`.

## 2. Capabilities
- **Multi-Level Filtering**:
  - Severity: `ALL`, `CRITICAL`, `WARNING`, `ADVISORY`, `INFO`
  - Text Search: Live filtering across rule IDs and descriptive explanations
- **Sorting**:
  - By Severity Weight (`CRITICAL` > `WARNING` > `ADVISORY` > `INFO`)
  - By Measured Dimension Value
- **Finding Inspection Card**:
  - Rule ID & Version (e.g. `DFM-WALL-001 v1.0`)
  - Observed Measurement vs Expected Threshold
  - Severity badge with high-contrast color coding
  - Concise engineering explanation
  - Spatial pin linkage to 3D Canvas
