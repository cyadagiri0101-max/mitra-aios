## 1. Mathematical Formulation

1. **Ridge Linear Regression:**
   Given augmented feature matrix $\tilde{X} = [\mathbf{1}, X] \in \mathbb{R}^{n \times (d+1)}$ with regularization penalty matrix $\Gamma = \text{diag}(0, \alpha, \alpha, \dots, \alpha)$:
   $$\theta^* = (\tilde{X}^T \tilde{X} + \Gamma)^{-1} \tilde{X}^T y$$
   Solved deterministically via Gaussian elimination with partial pivoting in `G14ModelTrainingService`.
2. **Deterministic Closed-Form Stability:**
   Guarantees reproducible, deterministic, local-first model training in TypeScript without external Python, C++, or cloud service dependencies.
3. **Calibrated Probability Estimation:**
   $$P(\text{delay}) = \sigma\left(\frac{\hat{y} - 2.0}{6.0}\right) = \frac{1}{1 + \exp\left(-\frac{\hat{y} - 2.0}{6.0}\right)}$$
4. **Artifact Schema:**
   Persisted in `g14_model_artifacts` with weights $[w_1, \dots, w_{20}]$, intercept $w_0$, residual standard deviation $\sigma$, and SHA-256 provenance signature.
