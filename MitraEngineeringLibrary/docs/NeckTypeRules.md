# Neck Type Rules

This document captures neck-type abbreviations from the Phase 1 dataset.

## Known mappings

- `CN` ⇒ `Captured Neck`
- `FN` ⇒ `Flash Neck`
- `LH` ⇒ `Lost Head`
- `AN` ⇒ `Angle Neck`
- `TN` ⇒ `Tottle Bottle`

## Observed neck-type tokens

- `CN`
- `FN`

## Guidance

- Map neck tokens to the known neck rules only when they appear exactly.
- Preserve unknown neck tokens for future review.
