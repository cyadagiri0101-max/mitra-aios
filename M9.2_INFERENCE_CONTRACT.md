# M9.2 — Inference Contract Specification
## REST Endpoints, Payloads & Output Structure
**Milestone:** `M9.2`  
**Status:** **AUTHORITATIVE**

---

## 1. Inference API Endpoints

- `POST /api/predictive/models/train`
  - Input: `{ featureVersion?: string, regularizationAlpha?: number, minSamplesThreshold?: number }`
  - Output: `G14ModelArtifact`
- `GET /api/predictive/models/active`
  - Output: `G14ModelArtifact`
- `POST /api/predictive/delay/predict`
  - Input: `{ projectId: string, predictionCutoff?: string, confidenceIntervalPct?: number }`
  - Output: `G14PredictionResult`
