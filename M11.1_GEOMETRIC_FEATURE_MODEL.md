# M11.1 — Geometric Feature Model Specification
## Canonical Representation of Extracted Features
**Milestone:** `M11.1`  
**Status:** **AUTHORITATIVE**

---

## 1. Supported Feature Types

- `PART_BOUNDING_BOX`: Length, width, height, envelope volume.
- `WALL_THICKNESS`: Nominal, minimum, and maximum wall thickness.
- `DRAFT_ANGLE`: Minimum draft angle on core/cavity sides.
- `RIB`: Thickness, height, rib-to-wall aspect ratio.
- `BOSS`: Outer diameter, inner core diameter, wall thickness.
- `HOLE`: Diameter, depth, depth-to-diameter aspect ratio.
- `FILLET_RADIUS`: Minimum radius and sharp-corner flags.
