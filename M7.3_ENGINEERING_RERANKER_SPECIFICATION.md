# M7.3 — Engineering Feature Reranker Specification
## Deterministic Feature Scoring & Domain Weighting Architecture
**Milestone:** `M7.3`  
**Status:** Certified Specification  
**Module:** `src/modules/engineering-library/retrieval`

---

## 1. Domain Feature Boosts

The engineering reranker applies explicit, deterministic additive boosts to the base normalized fusion score:

| Feature | Condition | Boost Value |
| :--- | :--- | :---: |
| **Exact Project Match** | `chunk.projectNumber === filter.projectNumber` | $+0.30$ |
| **Partial Project Match** | `chunk.projectNumber.includes(filter.projectNumber)` | $+0.15$ |
| **Exact BOM Part Description**| `query.includes(bom.description)` | $+0.25$ |
| **Exact Machine Match** | `chunk.machine === filter.machine` | $+0.20$ |
| **Exact Material Match** | `chunk.material === filter.material` | $+0.20$ |
| **Exact Query Phrase** | `chunk.chunkText.includes(query)` | $+0.15$ |

---

## 2. Authority Multiplier Factors

The boosted score is scaled by the document authority status:

$$\text{FinalScore} = \text{clamp}_{[0, 1]}\left((\text{FusionScore} + \sum \text{Boosts}) \times \text{AuthorityFactor}\right)$$

| Authority Status | Factor | Rationale |
| :--- | :---: | :--- |
| **`AUTHORITATIVE_RELEASE`** | $1.00$ | Production-certified engineering baseline |
| **`CURRENT_WORKING`** | $0.90$ | Active engineering design in progress |
| **`HISTORICAL_REFERENCE`** | $0.70$ | Historical legacy information |
| **`SUPERSEDED`** | $0.30$ | Deprecated / superseded revision |
