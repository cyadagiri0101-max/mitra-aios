# M11.3 Engineering Recommendation Specification

## 1. Advisory Recommendation Types
- `REVIEW_GEOMETRY`: Comprehensive geometric review against baseline DFM standards.
- `INCREASE_WALL_THICKNESS`: Specific recommendation to thicken cavity sections against polymer freeze-off.
- `INCREASE_DRAFT`: Recommendation to increase side draft angle against ejection scuffing.
- `REDUCE_RIB_RATIO`: Recommendation to lower rib root thickness to eliminate sink marks.
- `REVIEW_HOLE_DEPTH`: Recommendation to reduce core pin aspect ratio against flow deflection.
- `REVIEW_TOOLING`: Tool insert modification and cooling line realignment.
- `REVIEW_PROCESS`: Molding temperature, injection pressure, and holding time tuning.
- `RUN_TRIAL`: Physical trial run recommendation when shop floor defect evidence is insufficient.
- `REVIEW_MATERIAL`: Polymer resin grade substitution advice.
- `REQUEST_ENGINEERING_APPROVAL`: Governance escalation for critical non-conformances.

## 2. Human Review State Machine
$$\text{GENERATED} \longrightarrow \text{UNDER\_REVIEW} \longrightarrow \begin{cases} \text{ACCEPTED} \\ \text{MODIFIED} \\ \text{REJECTED} \\ \text{CANCELLED} \end{cases}$$
