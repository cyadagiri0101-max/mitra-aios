# M9.5 — Human Approval State Machine Specification
## Recommendation Lifecycle & Human Authority Boundaries
**Milestone:** `M9.5`  
**Status:** **AUTHORITATIVE**

---

## 1. State Machine Workflow

```
GENERATED
   │ (reviewRecommendation)
   ▼
UNDER_REVIEW ──────────► REJECTED (rejectRecommendation)
   │
   ├───────────────────► MODIFIED (modifyRecommendation)
   │                        │
   │ (acceptRecommendation) │ (acceptRecommendation)
   ▼                        ▼
ACCEPTED ──────────────► CANCELLED (cancelRecommendation)
   │
   │ (applyRecommendation with explicit confirmExecution = true)
   ▼
APPLIED
   │
   └── (if expiresAt < now()) ──► EXPIRED
```

---

## 2. Mandatory Human Authority Invariants

1. AI models **never** create recommendations in `APPLIED` state.
2. Only an authorized human planner can transition a proposal to `APPLIED`.
3. If modified by a human planner, `_originalAiProposal` is preserved in the proposed state for auditability and model feedback analysis.
