# M11.4 Assumption UI Specification

## 1. Assumption Governance
Tracks domain assumptions:
- `VERIFIED`: Explicitly confirmed against authoritative ERP/QMS/PLM master data (e.g. Verified ABS polymer resin material spec, Verified injection molding tooling routing).
- `UNVERIFIED_ASSUMPTION`: Default or inferred parameters requiring engineer validation.

## 2. Confidence Impact
Unverified assumptions apply deterministic penalties to the overall confidence score calculation, visually highlighted with amber warning badges.
