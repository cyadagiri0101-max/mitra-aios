# M11.1 — EKOS Integration Specification
## Lineage Projection for Geometric Features & DFM Findings
**Milestone:** `M11.1`  
**Status:** **AUTHORITATIVE**

---

## 1. Graph Projection Schema

- **Geometric Feature:** Projected as `CAD_MODEL` node linked to `DRAWING` via `REFERENCES` edge.
- **DFM Finding:** Projected as engineering risk node (`NCR`) linked to `CAD_MODEL` via `OBSERVED_IN` edge.
- All projections maintain fail-closed tenant scoping and drawing revision isolation.
