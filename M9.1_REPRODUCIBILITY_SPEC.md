**Milestone:** `M9.1`

## 1. Deterministic Guarantees

1. **Deterministic Reconstruction:** Given $(tenantId, projectId, predictionCutoff, featureVersion)$, the extraction pipeline produces identical feature values.
2. **Cryptographic Source Hash:** `sourceRecordsHash` is computed as a SHA-256 digest over the sorted tuple IDs of all contributing milestones, work orders, NCRs, trials, and baselines.
3. **Idempotent Snapshotting:** Re-extracting features for the exact same cutoff updates the unique record without duplicate row insertion.
