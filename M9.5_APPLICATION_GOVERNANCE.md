# M9.5 — Application Governance Specification
## Transactional Safety & Explicit Confirmation Enforcement
**Milestone:** `M9.5`  
**Status:** **AUTHORITATIVE**

---

## 1. Application Preconditions

1. **Explicit Confirmation:** Request must contain `confirmExecution: true`.
2. **Valid State:** Recommendation status must be either `ACCEPTED` or `MODIFIED`.
3. **Temporal Validity:** Current timestamp $\le \text{expiresAt}$.
4. **Target Entity Existence:** Referenced project, milestone, or work-order must exist in current tenant.
5. **Transactional Integrity:** Schedule mutation executes inside a serializable database transaction; rollback on any failure.
