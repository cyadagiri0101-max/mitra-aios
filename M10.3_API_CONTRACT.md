# M10.3 — Manufacturing Telemetry REST API Contract Specification
## Endpoint Definitions, Payloads & Response Schemas
**Milestone:** `M10.3`  
**Status:** **AUTHORITATIVE**

---

## 1. REST Endpoints Ledger

- `POST /api/manufacturing/telemetry/ingest`: Ingest a single telemetry signal.
- `POST /api/manufacturing/telemetry/batch`: Ingest a batch of telemetry signals.
- `GET /api/manufacturing/telemetry/:machineId`: Query recent machine signals.
- `POST /api/manufacturing/observations`: Record an operator / trial observation.
- `GET /api/manufacturing/work-orders/:workOrderId/feedback`: Retrieve correlated signals and observations.
