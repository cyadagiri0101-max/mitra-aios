# M11.3 Security & Tenant Isolation Governance

## 1. Authentication & RBAC
- All reasoning and cost endpoints are protected by `JwtAuthGuard` and `RolesGuard`.
- Roles permitted for reasoning generation & review: `ADMIN`, `ENGINEERING`, `QUALITY`, `PLANNING`.
- Cost configuration modifications restricted to: `ADMIN`, `ENGINEERING`, `FINANCE`, `PLANNING`.

## 2. Fail-Closed Tenant Isolation
- Requests without a valid `tenantId` are rejected immediately with `403 ForbiddenException`.
- Database queries enforce strict `tenant_id` WHERE clauses on `engineering_reasoning_results` and `engineering_cost_configurations`.
- Cross-tenant lookups fail closed with `404 NotFoundException`.
