# M11.3 Evidence Contract Specification

## 1. Evidence Preservation Rules
Every reasoning step and impact assessment must cite concrete, traceable evidence items.

## 2. Evidence Schema
```typescript
export interface EvidenceItem {
  evidenceId: string;
  evidenceType: EvidenceType;
  sourceEntity: string;
  sourceId: string;
  sourceRevision: string | null;
  tenantId: string;
  projectId: string;
  timestamp: string;
  provenance: Record<string, any>;
  sourceHash: string | null;
  metadata: Record<string, any>;
}
```

## 3. Supported Evidence Types
- `GEOMETRIC_FEATURE`: Extracted CAD features and measurements.
- `DFM_FINDING`: Deterministic DFM rule evaluation records.
- `HISTORICAL_NCR`: Shop floor non-conformance reports.
- `TRIAL_OBSERVATION`: Physical molding trial test records.
- `CAPA`: Corrective and preventive action lineage.
- `DRAWING_REVISION`: Versioned engineering drawings.
- `MATERIAL`: Polymer/alloy property sheets.
- `PROCESS_PLAN`: Authoritative routing operations.
- `EKOS_LINEAGE`: Multi-hop graph relation traces.
