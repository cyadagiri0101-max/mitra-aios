## 1. Failure Injection Scenarios
- **FI-01 (Cross-Tenant Workspace Leakage)**: Tenant B attempts to request analysis workspace for a drawing owned by Tenant A. Result: Fail-closed; 0 features, 0 findings, 0 reasoning results returned.
- **FI-02 (Cross-Tenant Review Injection)**: Tenant B attempts to submit a review decision on a reasoning result belonging to Tenant A. Result: Immediate rejection with error.
- **FI-03 (3D WebGL Context Loss / Unsupported Hardware)**: 3D canvas throws error. Result: Caught by React error boundary; immediately transitions to structured 2D tabular engineering fallback mode (`CadCanvasFallbackSummary`). Engineering review workflow remains 100% functional.
- **FI-04 (Unconfigured Cost Rates)**: Rates missing from cost configuration table. Result: Handled cleanly without fabricating numbers, displaying `COST_NOT_CONFIGURED` (`UNAVAILABLE`).
- **FI-05 (Missing Decision Notes)**: Human decision submitted without required engineering rationale. Result: Frontend and backend validation reject submission.
