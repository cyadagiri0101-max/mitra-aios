## 1. Security Architecture Summary

- **Tenant Isolation:** `TenantAwareService` and parameterized repository queries enforce strict tenant scoping across all 40 modules. Cross-tenant IDOR attacks fail closed.
- **RBAC Matrix:** `RolesGuard` and `@Permissions` govern write, review, and approval operations.
- **Published Knowledge Immutability:** State machines permanently lock published articles and attached evidence against in-place edits.
- **Citation Anti-Spoofing:** All attached evidence references are physically validated against real `knowledge_chunks` before linking.
- **AI Prompt-Injection Defenses:** Grounding context builder sanitizes input tokens and enforces strict citation verification.
