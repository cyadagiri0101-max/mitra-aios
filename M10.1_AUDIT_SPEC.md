# M10.1 — Audit Specification
## Governed Audit Event Ledger for EKOS Lineage Graph
**Milestone:** `M10.1`  
**Status:** **AUTHORITATIVE**

---

## 1. EKOS Audit Events

- `EKOS_LINEAGE_NODE_REGISTERED`: Emitted when an entity node is projected into the graph.
- `EKOS_LINEAGE_EDGE_RECORDED`: Emitted when a semantic relationship is created or updated.
- `EKOS_INTEGRITY_CHECKED`: Emitted upon graph health verification.
