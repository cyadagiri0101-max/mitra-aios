## Air-Gapped Local Vector Indexing Pipeline via Ollama & pgvector
**Milestone:** `M7.2`  
**Status:** Certified Architecture  
**Module:** `src/modules/engineering-library/embeddings` & `src/modules/ai`

---

## 1. Local-First Embedding Principles

1. **Strictly Local Execution:**
   - Vector generation runs entirely on local infrastructure via `OllamaProvider` pointing to local Ollama instance (`http://localhost:11434`).
   - Standardized on `nomic-embed-text` (768 dimensions).
   - Zero dependency on third-party cloud APIs.

2. **Offline Deterministic Fallback:**
   - In air-gapped dev or CI/CD test environments where Ollama is not active, `EmbeddingService` generates deterministic, normalized 768-dimensional vectors from SHA-256 tokens to guarantee test determinism and pipeline continuity.

3. **Graceful Degradation & Batch Resumability:**
   - If Ollama encounters a timeout or network error, individual chunks are marked `embeddingStatus: FAILED` with error logs.
   - The batch continues processing remaining chunks, and failed items can be retried without re-processing completed chunks.

4. **Dimension Validation:**
   - Validates vector dimensions ($D = 768$) against the database schema to prevent silent vector truncation or padding.
