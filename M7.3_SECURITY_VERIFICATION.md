## 1. Multi-Tenant Enforcement Architecture

- **Database-Level Isolation:** Every lexical query, vector similarity scan, and entity join strictly appends `WHERE c.tenant_id = :tenantId`.
- **Tenant Context Injection:** Handled via `TenantAwareService.requireTenant()` ensuring no request can execute without an explicit, valid tenant UUID.
- **pgvector Isolation:** The vector similarity query filters on `knowledge_chunks.tenant_id = $2` and `knowledge_embeddings.tenant_id = $2` before sorting.
