# M8.5 — Governed Knowledge Search Specification
## Quality Gate Filtering, Tenant Isolation & Evidence Enrichment
**Milestone:** `M8.5`  
**Target Service:** `KnowledgeSearchService`  
**Status:** **SPECIFICATION COMPLETE**

---

## 1. Default Search Filtering Rules

In MITRA, public organizational knowledge search must deliver only signed-off, current, and active articles.

### Mandatory Default Predicate:
```sql
WHERE "a"."status" = 'PUBLISHED'
  AND "a"."is_latest" = true
  AND "a"."tenant_id" = :tenantId
  AND "a"."deleted_at" IS NULL
```

### Excluded by Default:
- `DRAFT` (Work in progress)
- `UNDER_REVIEW` (Pending quality sign-off)
- `REJECTED` (Disapproved draft)
- `SUPERSEDED` (Obsolete historical version)
- `EXPIRED` (Outdated document)
- `ARCHIVED` (Decommissioned knowledge)
- `deleted_at IS NOT NULL` (Soft-deleted records)
- Cross-tenant records (`tenant_id != currentTenant`)

---

## 2. Parameterized Filter Extensions

- **`projectId`:** `AND "a"."project_id" = :projectId`
- **`decisionId`:** `AND "a"."decision_id" = :decisionId`
- **`articleType`:** `AND "a"."article_type" = :articleType`
- **`status`:** (Allowed only when caller explicitly overrides with authorized filter).

---

## 3. Evidence Enrichment in Search Results

When returning article search results, the service attaches an array of validated evidence citations (`evidence: [...]`), showing authoritative sources, coordinates, and labels for each result.
