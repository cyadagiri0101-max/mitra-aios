# M8.4 — Knowledge Article Draft Generation Specification
## Field Mapping, Structured Markdown Synthesis & Provenance Invariants
**Milestone:** `M8.4`  
**Target Output:** `KnowledgeArticle` in `DRAFT` state  
**Status:** **SPECIFICATION COMPLETE**

---

## 1. Field Mapping Specification

| EngineeringDecision Field | KnowledgeArticle Field | Transformation / Synthesis Rule |
|:---|:---|:---|
| `title` | `title` | `"Engineering Decision: " + decision.title` |
| `title` + `version` | `slug` | Deterministic unique slug derived from decision title (e.g. `engineering-decision-cooling-layout`) |
| `decisionType` | `articleType` | Mapped: `DESIGN`/`PROCESS`/`MATERIAL_SELECTION` $\rightarrow$ `BEST_PRACTICE`, `QUALITY`/`TRIAL` $\rightarrow$ `LESSON_LEARNED`, default `PROCEDURE` |
| `rationale` / `description` | `summary` | Concise abstract derived from `decision.rationale` (fallback to `decision.description`) |
| Structured Decision Fields | `content` | Generated Markdown document with formal headers (Context, Statement, Options, Rationale, Governance) |
| `id` | `decisionId` | Foreign reference link (`decision_id = decision.id`) |
| `projectId` | `projectId` | Foreign reference link (`project_id = decision.projectId`) |
| `decisionType` | `tags` | `['engineering-decision', decision.decisionType.toLowerCase(), ...]` |
| N/A | `status` | Strictly initialized to **`DRAFT`** |
| N/A | `version` | Initialized to **`1`** |
| N/A | `isLatest` | Initialized to **`true`** |
| N/A | `parentArticleId` | Initialized to **`null`** |
| N/A | `supersededById` | Initialized to **`null`** |

---

## 2. Generated Markdown Format

```markdown
# Engineering Decision: <title> (<decisionNumber>)

## Context & Background
<context or description or "No additional context provided.">

## Decision Statement
<decision or "Decision details documented in decision log.">

## Options Considered
<optionsConsidered or "Options evaluated by engineering team.">

## Selected Option & Rationale
- **Selected Option:** <selectedOption>
- **Engineering Rationale:** <rationale>

## Decision Governance Metadata
- **Decision Number:** `<decisionNumber>`
- **Decision Type:** `<decisionType>`
- **Approval Status:** `<status>`
- **Approved At:** `<approvedAt>`
- **Approved By:** `<approvedBy>`
```

---

## 3. Mandatory Human Review Invariant

The generated article is created in `DRAFT` state. It cannot be published automatically.
To transition to `PUBLISHED`, the article must be formally submitted (`/submit`) and approved by a Quality/Admin reviewer (`/approve` / `/publish`) following the certified M8.2 lifecycle state machine.
